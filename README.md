# 피수민 포트폴리오 (데이터 분석가)

순수 HTML/CSS/JS로 만든 데이터 분석가 포트폴리오 사이트입니다. 빌드 도구 없이 바로 브라우저에서 열어볼 수 있습니다.

**배포 주소: https://psm-data-portfolio.vercel.app**

## 프로젝트

| 프로젝트 | 내용 | 상세 페이지 |
|---|---|---|
| BeautyGuard | 검색 수요·시장 공급·소비자 리뷰를 성분 단위로 묶은 화장품 MD용 시장 분석 대시보드 | `projects/beautyguard.html` |
| J-CREW | 유소년 농구교실을 위한 관리 플랫폼, 출결 기록 기반 이탈 위험 지표 | `projects/jcrew.html` |
| JejuTrip AI | 직접 수집한 관광지·리뷰 데이터 기반 제주 여행 코스 추천 서비스 | `projects/jejutrip.html` |

## 미리보기

`index.html` 파일을 브라우저로 열거나, VSCode의 Live Server 확장으로 열어보세요.

## 폴더 구조

```
index.html                    메인 페이지
css/style.css                 스타일 (다크/라이트 테마)
js/script.js                  인터랙션 (스크롤 애니메이션, 스킬 툴팁 등)
assets/icons/                 프로젝트 로고/아이콘
assets/screenshots/           프로젝트 상세 페이지 화면 캡처
projects/*.html               프로젝트 상세 페이지
```
